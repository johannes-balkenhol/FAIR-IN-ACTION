# One-page FAIR checklist

Tick as you go. Every item is objective — no judgement calls.

## 🥉 Bronze — setup (free; do it first)
- [ ] Domain and unit of study identified (`domains/`)
- [ ] Sensitivity decided (open / restricted / pseudonymised / identifying)
- [ ] Licence chosen (data and code)
- [ ] Folder structure created; raw/ locked read-only and checksummed
- [ ] README with a data-availability section
- [ ] Data steward named
- [ ] Repository chosen

## 🥈 Silver — the real bar (someone else can reuse it without asking you)
- [ ] Machine-readable fields extracted, not typed
- [ ] Human-only fields filled, each with a stated reason
- [ ] Controlled-vocabulary terms used where they exist (no free text; no wrong terms)
- [ ] Provenance captured (protocol, software version, operator, date)
- [ ] Persistent identifier obtained (accession and/or DOI)
- [ ] A data management plan exists

## 🥇 Gold — a reusable research object
- [ ] Identifiers cross-linked (code ↔ data ↔ paper, both ways)
- [ ] Contributors credited with ORCIDs
- [ ] Environment pinned so the analysis re-runs
- [ ] The setup reused by a second project

*A project that is not bronze has not been neglected — it has not been set up.*
